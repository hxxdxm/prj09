# Day 06 — OCR 검사 결과 및 실패 분석

## 1. 정상 제품 이미지 6장 검사

확정한 OCR 설정(`day06-ocr-v1.0`)을 제품 이미지 6장에 동일하게 적용했다.

| 설정 항목 | 적용 값 |
|---|---|
| 전처리 | `original` (원본 ROI 사용) |
| 이미지 확대 | 4배 |
| OCR 엔진 | Tesseract 4.1.1 (`PSM 7`: 한 줄 문자 인식) |
| Whitelist | 숫자 `0~9`만 허용 |
| Regex | `^[0-9]{13}$` (숫자 13자리) |

| 평가 항목 | 결과 | 의미 |
|---|---|---|
| OCR 정확도 | **6/6 (100%)** | 실제 인쇄된 SN을 모두 정확하게 읽음 |
| 제품 판정 정확도 | **6/6 (100%)** | OK 4장, 교육용 NG 2장을 모두 정답대로 판정 |
| Expected 일치 | 4/6 | NG 2장은 OCR은 정확했지만 Expected SN과 달라 `NG_EXPECTED_MISMATCH` |

> 제품 판정 정확도 100%는 모든 제품이 OK라는 뜻이 아니라, OK와 NG를 모두 올바르게 구분했다는 뜻이다.
> OCR이 문자를 정확히 읽는 것과 제품이 정상인 것은 서로 다른 문제다.

### 전처리 비교 (대표 SN `0637145699424`)

| 전처리 | OCR 결과 | 정확 |
|---|---|---|
| original | `0637145699424` | O |
| gray | `0637145699424` | O |
| clahe | `0637145699424` | O |
| otsu | `0637245699424` | X (`1`을 `2`로 읽음) |
| clahe_otsu | 빈 값 | X |

이진화(Otsu)를 하면 얇은 숫자 획이 끊기거나 뭉개져 오히려 OCR이 나빠졌다.
가장 단순한 `original`을 최종 전처리로 선택했다.

## 2. 영상 상태 변화 테스트

같은 SN `0637145699424`에 흐림·기울기·빛 반사를 적용하고, OCR 설정은 바꾸지 않은 채 다시 검사했다.

| 테스트 조건 | 실제 OCR 결과 | 인식 성공 | NG Reason | 확인한 내용 |
|---|---|---|---|---|
| Low Contrast | `0637145699424` | **성공** | - | 글자가 옅어져도 정확히 인식함 |
| Blur | 빈 값 | 실패 | OCR_EMPTY, FORMAT, EXPECTED_MISMATCH | 숫자 획이 흐려져 읽지 못함 |
| Tilt | `2` | 실패 | FORMAT, EXPECTED_MISMATCH | 13자리 중 1자리만 잘못 읽음 |
| Tilt + Deskew (-8°) | `4` | 실패 | FORMAT, EXPECTED_MISMATCH | 단순 회전 보정만으로 복구되지 않음 |
| Glare | 빈 값 | 실패 | OCR_EMPTY, FORMAT, EXPECTED_MISMATCH | 반사로 문자 정보가 가려져 읽지 못함 |

**결과: 5개 조건 중 성공 1개, 실패 4개.**
여기서 실패는 OCR 인식 실패이며, 제품에 SN이 잘못 인쇄되었다는 뜻이 아니다.

교재 실행 결과(Tilt `9728`, Tilt+Deskew 빈 값)와 Tilt에서 읽힌 글자는 달랐지만,
실패한 OCR이 엉뚱하게 읽은 값이라 Tesseract 환경에 따라 달라질 수 있는 부분이다.
성공·실패 패턴은 교재와 같았다.

## 3. 결과 해석과 개선 방향

정상 이미지에서는 OCR과 제품 판정이 모두 정확했지만, 영상 품질이 바뀌면 같은 OCR 설정도 문자를 읽지 못했다.
현재 `day06-ocr-v1.0`은 Low Contrast에는 강하지만 Blur, Tilt, Glare에는 약하다.

개선 순서:

1. **촬영 환경 개선:** 초점·셔터속도로 흐림을 줄이고, 조명 각도를 바꿔 반사를 줄인다.
2. **전처리·설정 재검토:** 기울기를 실제로 측정해 보정하고, 대비·확대율·PSM을 바꿔 다시 비교한다.
3. **재평가:** 바꾼 설정을 정상 이미지와 실패 이미지에 모두 적용해 실제로 좋아졌는지 확인한다.
4. **필요한 경우:** 다른 OCR 엔진을 비교하거나 다양한 조건의 데이터로 학습 가능한 OCR 모델을 검토한다.

> 이번 테스트는 어떤 조건에서 OCR이 실패하는지 찾아낸 실험이다.
> 2일차 glare, 4일차 tilt_glare와 같이, 촬영환경이 나쁘면 소프트웨어 보정만으로 되살리기 어렵다.
