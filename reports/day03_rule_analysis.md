# Day 03 Mini Challenge 결과

## 1. 검사 문제
검사 대상: 영양제 병의 주황색 병뚜껑
정상 상태: 병 입구에 주황색 뚜껑이 있음 (OK)
불량 상태: 뚜껑이 없어 투명한 병목이 보임 (NG)

## 2. 사용한 처리
처리 흐름:
ROI (이미지 비율 0.300, 0.109, 0.735, 0.336)
→ HSV 변환
→ 주황색 Mask (H 5~20, S 120~255, V 80~255)
→ Morphology (Opening → Closing, 5×5 타원 Kernel)
→ Contour (ROI의 1% 미만 덩어리 제외)
→ Feature 측정

색상이 검사 기준이므로 Gray 대신 HSV를 선택했다.

## 3. 선택한 Feature
Feature: orange_ratio (ROI 안에서 주황색 픽셀이 차지하는 비율)
선택 이유:
- 뚜껑이 있으면 ROI의 약 43%가 주황색이고, 없으면 거의 0이다.
- 병목과 배경은 주황색이 아니므로, 뚜껑이 없을 때 값이 크게 떨어진다.
- 22번 Batch의 Gray 면적 비율(정상 0.44 / 불량 0.28)보다 차이가 훨씬 크다.

## 4. 실제 측정값
| 이미지 | 역할 | orange_ratio | valid_count |
|---|---|---:|---:|
| ok_01 | Calibration | 0.4306 | 1 |
| ng_01 | Calibration | 0.0012 | 0 |
| ok_02 | Test | 0.4298 | 1 |
| ok_03 | Test | 0.4374 | 1 |
| ng_02 | Test | 0.0007 | 0 |

정상: 0.430 ~ 0.437
불량: 0.0007 ~ 0.0012

## 5. Rule
기준값: ok_01과 ng_01의 orange_ratio 가운데 = 0.2159
OK 조건: orange_ratio >= 0.2159
NG 조건: orange_ratio <  0.2159
NG Reason: NG_NO_ORANGE_CAP (주황색 뚜껑 없음)

## 6. 새로운 이미지 확인
확인한 이미지 수: 3 (ok_02, ok_03, ng_02)
올바른 판정: 3
틀린 판정: 없음
가장 기준에 가까운 이미지: ok_02 (기준과의 차이 +0.2139)

## 7. 결과 해석
잘 동작한 부분:
- 정상과 불량의 차이가 약 0.43으로 커서, 모든 Test 이미지가 기준에서 0.21 이상 떨어져 있었다.
- 병 안의 빨간 종이학은 ROI 밖에 있고 색상 범위(H 5~20) 밖이라 영향이 없었다.

문제가 있었던 부분:
- 사진마다 병 위치가 좌우로 약 80px 달라서, 1일차 ROI로는 뚜껑이 잘렸다.
- 불량 이미지 Mask 윗부분에 모니터 작업표시줄의 주황색 아이콘이 작은 점으로 잡혔다.
  (최소 면적 조건으로 걸러져 판정에는 영향 없음)

수정한 내용:
- ROI를 5장의 뚜껑 위치를 모두 포함하도록 넓혔다. (교재 23번 B. ROI를 조금 넓혀야 함)
- 해상도가 달라도 같은 위치를 자르도록 ROI를 픽셀이 아니라 이미지 비율로 지정했다.

## 8. 결론
가장 중요했던 Feature: orange_ratio
색이 뚜렷한 물체는 Gray 면적보다 HSV 색상 Mask가 훨씬 안정적으로 구분했다.

이 Rule이 실패할 수 있는 조건:
- 모니터 화면이나 주변 물체에 주황색이 크게 들어오는 경우 (배경 영향)
- 조명 색이 바뀌어 뚜껑의 색상(H) 값이 범위를 벗어나는 경우
- 병 위치가 ROI 밖으로 크게 벗어나는 경우
- 뚜껑 색이 주황이 아닌 제품을 검사하는 경우
- 뚜껑이 반쯤 열려 orange_ratio가 기준 근처에 오는 경우 (아직 확인 안 함)
